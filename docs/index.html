Homeserver Orchestrator

Lightweight Raspberry Pi & Linux Cluster Manager

Deploy homeserver apps, customize ports, and auto-route domains through a secure, self-hosted Nginx reverse proxy.

curl -fsSL https://pimanager.github.io/piman/install.sh | bash

Multi-Node Cluster

Orchestrate workloads across a cluster of Raspberry Pis or local servers over secure SSH connections.

Dynamic Port Overrides

Customize host port mappings before deployment dynamically, avoiding port collision across services.

Inbound Domain Router

Managed Nginx proxy auto-discovers active services and maps custom domains to your cluster workloads.

Web Console Manager

Manage configurations, SSH credentials bootstrap, catalog synchronization, and health logs visually.
